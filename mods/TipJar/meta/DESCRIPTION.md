A simple multiplayer **Tip Jar** for **Lucid Cats**. Deposit credits into the jar and anyone can withdraw them later.

## Features

* Shared multiplayer Tip Jar in the lobby.
* Host configurable transfer amount, jar capacity and deposit fee.
* Client configurable withdrawal key.
* The jar visually fills as credits are deposited.

## Configuration

After one launch, edit `BepInEx\config\io.github.maxmen11.lucidcats.tipjar.cfg`:
transfer amount, capacity and deposit fee (host); withdrawal key (each client).
